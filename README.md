# Remote Morse Key System

WebSocket-basiertes Remote-Morse-System mit ESP32/ESP8266.

## Hardware
- **Sender**: LOLIN D1 Mini (ESP8266)
- **Empfänger**: WT32-ETH01 (Ethernet)

## Features
- ✅ WiFi-Konfigurationsportal
- ✅ Straight Key & Iambic Paddle Support
- ✅ Einstellbare Geschwindigkeit (10-40 WPM)
- ✅ WebSocket-Kommunikation
- ✅ Web-Interface für Status

## Installation
1. Arduino IDE mit ESP32/ESP8266 Support
2. Bibliotheken: WebSockets
3. Code hochladen
